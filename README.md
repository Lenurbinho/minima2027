# Minima 2027

Athlètes français ayant réalisé les minima pour les championnats internationaux 2027,
à commencer par les **Championnats d'Europe en salle de Valencia** (4–7 mars 2027).

Site : https://lenurbinho.github.io/minima2027/

- `data/championnats.json` : épreuves, standards European Athletics, minima FFA, périodes, thème
- `data/achievements.json` : athlètes détectés (généré automatiquement)
- `index.html` : le site

Aperçu local : `python -m http.server 8027` puis http://localhost:8027
